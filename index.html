02 / THE METHOD

No black box.
A visible process.

TradeStack treats a trading strategy as a system to inspect and challenge—not a prediction to blindly trust.

“A useful system is one that makes its assumptions testable.”
01

Capture the market

Stream index and options data into a consistent analysis pipeline.

02

Form and filter a hypothesis

Evaluate setup logic, market context and predefined risk constraints.

03

Simulate, then record

Run paper execution with tracked lifecycle events and modeled fills.

04

Reproduce the outcome

Replay available recordings, review costs and adjust rules based on evidence.

03 / THE RESEARCH LAB

Results need context.
Especially the losses.

We aim to publish useful, clearly labeled research—not selective screenshots of winning trades. Performance reporting remains under validation while trade records, charges and exit classifications are reconciled.

  • ✓ Net performance after estimated trading costs
  • ✓ Winning and losing setups by market conditions
  • ✓ Drawdown, expectancy and exit-reason analysis
  • ✓ Replay completeness and model assumptions

06 / THE IMPORTANT DETAILS

Clear expectations.
Better conversations.

Can I connect my brokerage account and trade here?+

Not currently. This public website presents an independent research project; it is not a public trading service. The project's gateway currently supports restricted paper-trading sessions.

Are the results from live trading?+

No live-account performance is claimed here. Research and simulation results must be labeled and verified before publication.

Is TradeStack open source?+

This website's source is public on GitHub. Availability and licenses for other TradeStack components vary; not all system code is publicly available.

Where can I follow the project?+

Visit the website repository on GitHub for the latest website changes and feedback discussions.
