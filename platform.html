TRADESTACK / PLATFORM OVERVIEW

One research system.
Two connected services.

TradeStack combines a Python market-decision engine with a Node.js paper-trading dashboard. The architecture separates analytical logic, risk checks, account access and session reporting.

CORE ENGINE / PYTHON + FASTAPIPAPER-FIRST

Algo Execution Service

Consumes Upstox V3 Protobuf WebSocket market data, assembles analysis candles, evaluates options setups, gates candidate trades and simulates entries and exits.

  • 11 documented strategy classes, with multiple named setups
  • Multi-timeframe trend, VWAP, EMA, ADX, RSI and market structure
  • Layered signal gating, scoring and option liquidity checks
  • Daily drawdown checks, stop management and session exit controls
  • Tick/depth capture and replay through Parquet recordings
An internal research service, not a public live-order API. Strategy counts describe the documented implementation, not proven profitable setups.
APPLICATION / NODE.JS + EXPRESSAUTHENTICATED

Upstox Gateway & Dashboard

Provides account-restricted Upstox OAuth sessions and a browser workspace to operate paper sessions and inspect persisted trading history.

  • Sign-in via Upstox OAuth, with server-side session credentials
  • Start / stop paper sessions and inspect session health
  • Market snapshot, position, recorder and risk status views
  • Account-scoped trade, signal and session records from MongoDB
  • CSRF checks and account ownership validation
Current gateway code returns a disabled response for direct live order placement and modification.
