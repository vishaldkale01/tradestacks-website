02 / HOW IT OPERATES

Private session control.
Persistent trading history.

The public site and the paper-trading application have separate responsibilities. The real dashboard controls a private engine and requires authenticated sessions.

01 / AUTH

Broker-based sign-in

Upstox OAuth establishes a server-held broker session. The browser receives an HttpOnly session cookie and CSRF protection.

02 / CONTROL

Paper start and stop

The authenticated gateway forwards approved session controls to the Python service using a separate engine token.

03 / HISTORY

Per-account records

MongoDB-backed trades, sessions, signals and analytics are queried for the signed-in account.

04 / SAFETY

Live orders disabled

The current gateway explicitly returns a forbidden response for direct place/modify live-order routes.

03 / ACCESS AND RELEASE

A research workspace.
Not a public broker.

TradeStack's dashboard is available to configured accounts in the private development environment. Public registration, live-account results, brokerage execution and customer onboarding are not provided on this website.
